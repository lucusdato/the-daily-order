# The Daily Order

One historic battle a day. Read the situation like a commander, give the order that wins it, and watch it play out on a toy war table.

Plain static site, no build step on deploy. Open `index.html` or serve the folder.

- `index.html` is generated by `python3 build.py` from `_index.tpl`, `_css.txt`, `_extra.css` and `_defs.txt`. Run it after changing any of those.
- `js/` engine, daily mode, mystery format, scenes, combat effects, troop cards, glossary.
- `battles/` the ten step-by-step campaign battles.
- `tools/postkit.js` prints the day's X poll, link reply and next-day reveal: `node tools/postkit.js [day]`. `tools/sharemap.js [day]` writes the map picture for it to `maps/day-N.png` (needs Playwright).
- Short links: `/x`, `/share` and `/via/NAME` redirect to `/?ref=NAME` (see `netlify.toml`); `js/retain.js` remembers the source and clears it from the address bar.
- `daily/` daily scenarios. `manifest.js` lists the files to load. New battles go in a new `batch-NN.js` listed before `quick-01.js` and `mystery-01.js`.
